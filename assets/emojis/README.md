# Sodium Emoji Pack

This package contains 90 custom pixel-art reactions for Sodium.

## Contents

- **30 Sodium Core reactions:** salt shakers, salt crystals, wave characters, surfboard characters, and retro game hearts.
- **24 Surf Lore reactions:** surf animals, the snake, and the recurring blue-and-white foamie/kook character.
- **36 Chat Essentials:** universal reactions, money, planning, media, celebration, and food.

Every reaction is exported as an individually named **256 × 256 transparent PNG**. `emoji-manifest.csv` provides the display name, suggested shortcode, category, and relative filename. The `master-sheets` directory contains transparent overview sheets.

Suggested reaction-picker sections:

1. Sodium Core
2. Surf Lore
3. Chat Essentials

The artwork uses a deliberately limited pixel palette and hard transparency. Files should be displayed with nearest-neighbor scaling when enlarged.
