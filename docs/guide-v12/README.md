# Sodium Quick Start Guide V12 pages

These four JPEGs are the in-app rendering of `docs/SODIUM_Quick_Start_Guide_V12.pdf` for Sodium v1.57. They use the current application UI, sample crew content, the approved swirl icon, and Cyrus's supplied surf photography.

The Sessions page documents the current state model: orange cards are future plans, green cards are in the water, Play starts a surf, Stop finishes it, Share forwards it, and Edit changes or cancels it.
